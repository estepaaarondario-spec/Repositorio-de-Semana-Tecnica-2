# 🌸 Semana Técnica

Página interactiva en rosa pastel para guardar links, descripciones e imágenes de la Semana Técnica.

## Cómo publicarla en GitHub

1. Creá un repositorio nuevo en GitHub (por ejemplo `semana-tecnica`).
2. Subí `index.html` y `README.md` a la raíz del repositorio.
3. Andá a **Settings → Pages**.
4. En **Source** elegí **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
5. Guardá. En un minuto tu página estará en `https://TU-USUARIO.github.io/semana-tecnica/`.

## Cómo usarla

- **Agregar:** completá título, link y categoría. Opcionalmente sumá una **descripción** (hasta 250 caracteres) y una **imagen** de tu computadora, y tocá *Guardar*.
- **Imagen:** tocá *Elegir archivo* y seleccioná una foto. Se muestra una vista previa y se achica automáticamente (máx. 800 px) para ahorrar espacio.
- **Editar:** con el botón *Editar* de cada tarjeta podés cambiar título, link, categoría, descripción e imagen. Para cambiar la imagen elegí otra; para sacarla usá *Quitar imagen*. Si no tocás la imagen, se conserva la actual.
- **Borrar:** con el botón *Borrar* de cada tarjeta.
- **Filtrar:** por categoría o con el buscador (busca también en la descripción).
- **Exportar / Importar:** descargá todo (incluidas las imágenes) en un archivo `.json` para hacer copia o pasarlo a otra computadora.

## Importante

Los links, descripciones e imágenes se guardan en el navegador de quien usa la página (`localStorage`, límite aproximado de 5 MB). Cada persona ve sus propios datos; no se comparten automáticamente entre visitantes. Si agregás muchas imágenes y se llena el espacio, la página te avisa. Para compartir una lista, usá *Exportar* y pasale el archivo a otra persona para que lo *Importe*.
